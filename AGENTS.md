# AGENTS.md

Guidance for agents and for anyone working in this repository.

## What this repository is

Arknights operator voice lines, Korean

It is one of seven asset repositories split out of
[ArknightsGameDataEN](https://github.com/ThiagoVsky/ArknightsGameDataEN) so that no single repository grows past what GitHub
is comfortable hosting. Everything here is generated from the game; treat the contents
as machine output.

## Contents

Source: `audio/sound_beta_2/voice_kr/**` on the EN game server.

One directory per voice pack. Operator packs are `char_<operator_id>/`, holding that operator's clips as `cn_001.mp3`, `cn_024.mp3` and so on. Non-operator packs are `extra_<n>/`.

The clip numbers are the game's own dialogue keys, matching `charword_table.json` in ArknightsGameDataEN.

Format: MP3, 96 kbps mono

The game data refers to this set as `KR` in the `voiceLangDict` field of `charword_table.json`.

## How to work here

- **Do not hand-edit the asset files.** They are regenerated by the sync script and any
  manual change is lost on the next run. Fix the pipeline instead, in
  `tools/assets_sync.py`, which is a copy of the canonical script in
  [ArknightsGameDataEN](https://github.com/ThiagoVsky/ArknightsGameDataEN).
- **Regenerating**: `.github/workflows/update.yml` runs daily at 04:23 UTC. Trigger it
  by hand from the Actions tab (`Run workflow`), which is also the way to re-run after
  a failure. The `force` input reprocesses every bundle, ignoring the state.
- **Incremental state** lives in `.state/voice-kr.json` and is committed on purpose:
  it records which bundles were already extracted, keyed by the bundle hash from the
  server manifest. Without it every run would download the whole group again. Do not
  delete it unless you intend a full rebuild.
- **Uncommitted state or a cancelled run** is safe. Bundles are marked as done only
  after their files are written, so re-running resumes where it stopped.
- **Sizes**: this repository is expected to stay under GitHub's 1 GB recommendation.
  If it grows past that, say so rather than force-pushing: the fix is to split the
  group, and the way to do that is described in `tools/asset-repos/README.md` in the
  main repository.
- **Local run**:

  ```bash
  python -m pip install "arkprts[all]" lameenc
  python tools/assets_sync.py --out . --flat --state .state
  python tools/assets_sync.py --verify --out . --flat
  ```

  `tools/assets_sync.py` in this repository is self-contained: its default group is
  `voice-kr`, so no `--groups` argument is needed.

## Conventions

- **All code comments, docstrings, commit messages and documentation must be written in
  English**, in this repository and in every repository in this family. Portuguese text
  that already exists is legacy and must not be rewritten opportunistically; leave it
  alone unless the change you are making is specifically about that text.
- Keep the README and this file accurate when the pipeline changes: they are the only
  description of what the contents are.
- Nothing in this repository should require credentials. The sync reads public game
  servers only.

## Traps worth knowing

These are real defects already hit while building the pipeline, in case you need to
touch the extraction code:

- `UnityPy` cannot decompress the LZHAM-compressed bundles Arknights ships. arkprts
  registers its own LZ4AK decompressor in `CompressionHelper.DECOMPRESSION_MAP`, and
  that registration must happen **before** any `UnityPy.load` call.
- `obj.container` is a **string** in UnityPy 1.25, not a list. Iterating it directly
  yields one path per character.
- `AudioClip.m_AudioData` is usually `None`; the audio lives in the bundle's `.resource`
  and must be read through `clip.samples`, which returns `{name: bytes}` already
  decoded to WAV PCM.
- Bundles whose contents are only meshes, prefabs or shaders yield nothing extractable,
  so the raw `.ab` file is kept at the same path instead of being dropped.
- `TextAsset` objects are skipped on purpose: the game's text and JSON already live in
  the main data repository.
